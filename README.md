# Surfit Landing Page

Landing page COD (RTL، دارجة) - HTML + Tailwind CDN + Vanilla JS.

## التشغيل
افتح الفولدر ف VS Code، ثبّت extension **Live Server**، ثم كليك يمين على `index.html` > Open with Live Server.

## الهيكل
- `index.html` - الصفحة
- `css/style.css` - ستايلات مخصصة
- `js/main.js` - الكمية، العروض، التحقق من الفورم، الـ sticky CTA
- `assets/product-1..6.webp` - 1 أخضر، 2 بني، 3 أبيض، 4 أسود، 5 أحمر، 6 أزرق غامق

## التخصيص
- الأثمنة: `PRICES` ف `js/main.js` + قسم السعر ف `index.html`
- الألوان/المقاسات: `COLORS` و `SIZES` ف `js/main.js` + الفورم ف `index.html`
